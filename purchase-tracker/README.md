# 🧾 구매기록 통합 검색 (개인용 웹앱)

"로지텍 M650 마우스, 쿠팡에서 샀나 네이버에서 샀나?" — 상품 이름으로 검색하면
**어느 쇼핑몰에서, 언제, 얼마에** 샀는지 바로 보여 주는 나만의 웹앱입니다.

- 서버나 유료 호스팅이 필요 없습니다. **내 구글 계정 안에서만** 동작합니다
  (Google 스프레드시트 + Apps Script).
- 휴대폰 홈 화면에 추가해서 앱처럼 쓸 수 있습니다.
- 데이터는 내 스프레드시트에 쌓이므로, 앱 없이 시트에서 바로 봐도 됩니다.

## 무엇을 해 주나요?

| 기능 | 설명 |
|---|---|
| **상품명 검색** | `로지텍 m650`, `logitech`, `충전기` 등. 한글/영문 브랜드명을 같은 말로 취급하고, 띄어쓰기·대소문자는 무시합니다. 최신 구매가 위로 옵니다. |
| **Gmail 자동 수집** | 1시간마다 주문/결제 확인 메일을 읽어 상품명·브랜드·쇼핑몰·날짜·금액을 자동으로 기록합니다. 처음 실행하면 지난 1년 치 메일을 조금씩 거슬러 올라가며 채웁니다. |
| **캡처로 추가** | 쿠팡·네이버 등 앱의 **주문내역 화면을 캡처**해서 올리면 AI가 읽어 기록합니다. 메일이 안 오는 쇼핑몰도 이렇게 채울 수 있습니다. |
| **붙여넣기로 추가** | 주문내역 페이지, 카드 결제 문자, 카드 명세서 텍스트를 복사해 붙여넣으면 항목별로 정리됩니다. |
| **결제처 확인** | 카드 내역에 쇼핑몰 대신 **KG이니시스·토스페이먼츠·NHN KCP 같은 결제대행사**만 찍힌 결제를 모아, **같은 금액 + 3일 이내**의 주문 기록을 후보로 보여 줍니다. "이 주문의 결제가 맞아요"를 누르면 하나로 합쳐집니다. |

> 💡 핵심 아이디어: 카드 명세서에는 상품명이 없고 결제대행사 이름만 남는 경우가 많습니다.
> 반대로 **쇼핑몰의 주문확인 메일·주문내역 화면에는 상품명이 있습니다.** 그래서 상품 정보는
> 메일/캡처에서 가져오고, 카드 내역은 금액·날짜로 짝을 지어 "어디서 샀는지"를 찾아냅니다.

## 설치하기 (약 15분, 코딩 지식 불필요)

### 1단계. 스프레드시트와 스크립트 만들기

1. [Google 스프레드시트](https://sheets.new)에서 새 시트를 만들고 이름을 `구매기록`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 왼쪽 파일 목록의 `Code.gs` 내용을 모두 지우고, 이 폴더의
   [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣습니다.
4. 파일 목록 옆 **＋ → HTML** 을 눌러 이름을 `Index` 로 만들고(확장자 없이),
   [`apps-script/Index.html`](apps-script/Index.html) 내용을 붙여넣습니다.
5. 왼쪽 ⚙️ **프로젝트 설정** → **"appsscript.json" 매니페스트 파일을 편집기에 표시** 를 체크한 뒤,
   생긴 `appsscript.json` 내용을 [`apps-script/appsscript.json`](apps-script/appsscript.json) 으로 바꿉니다.
6. 💾 저장합니다.

### 2단계. 처음 실행 (권한 허용)

1. 편집기 위쪽 함수 선택 칸에서 `setup` 을 고르고 **▶ 실행** 을 누릅니다.
2. 권한 요청 창이 뜨면 본인 계정을 선택 → "고급" → "(안전하지 않음)으로 이동" → **허용**.
   (본인이 만든 스크립트라서 나오는 일반적인 경고입니다. 요청 권한: 이 스프레드시트 편집,
   Gmail **읽기 전용**, 외부 API 호출(Claude), 자동 실행 예약)
3. 실행 로그에 `설정 완료` 가 보이면 끝. 이제 1시간마다 메일을 자동으로 확인합니다.

### 3단계. AI 인식 켜기 (권장)

AI가 없어도 메일 제목과 금액으로 대략 기록은 되지만, **상품명·브랜드를 정확히 뽑고
캡처 이미지를 읽으려면** Claude API 키가 필요합니다.

1. <https://console.anthropic.com> 에서 가입 → 결제수단 등록 → **API Keys → Create Key**.
2. Apps Script 편집기 ⚙️ **프로젝트 설정 → 스크립트 속성 → 속성 추가**
   - 속성: `ANTHROPIC_API_KEY` / 값: 복사한 키 (`sk-ant-...`)
3. (선택) 비용을 더 줄이고 싶으면 속성 `CLAUDE_MODEL` 에 `claude-haiku-5-5` 를 넣으세요.
   기본값은 가장 정확한 `claude-opus-5-5` 입니다.

> 요금 감각: 메일·캡처 1건 처리에 보통 수 원~수십 원 수준입니다. 처음 1년 치를 채울 때만
> 메일 수만큼 비용이 들고, 이후에는 새 주문 메일만 처리합니다. Anthropic 콘솔에서
> 월 사용 한도를 걸어 두면 안심입니다.

### 4단계. 웹앱으로 배포 & 휴대폰에 설치

1. 편집기 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나** / 액세스 권한: **나만** → **배포**
2. 나오는 **웹 앱 URL** 을 휴대폰에서 엽니다 (같은 구글 계정으로 로그인).
3. iPhone: 공유 버튼 → **홈 화면에 추가** / Android(크롬): ⋮ → **홈 화면에 추가**.

> 코드를 수정했다면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 웹앱에 반영됩니다.

## 쇼핑몰 메일이 Gmail로 안 온다면?

자동 수집은 **이 스크립트를 설치한 Gmail 계정**의 메일만 읽습니다. 쇼핑몰 가입 이메일이
네이버 메일 등 다른 곳이라면 다음 중 하나를 하세요.

- **네이버 메일 → Gmail 자동 전달**: 네이버 메일 환경설정 → 자동분류/전달 설정에서
  쿠팡·네이버페이 등 발신자의 메일을 Gmail로 전달.
- 쇼핑몰 회원정보의 이메일을 Gmail로 변경.
- 메일이 없는 쇼핑몰(앱 주문 위주)은 **주문내역 캡처**로 추가.

## 과거 구매를 한 번에 채우는 요령

1. 쿠팡/네이버/11번가 앱 → 주문목록 화면을 스크롤하며 여러 장 캡처 → "추가" 탭에서 하나씩 업로드.
2. 카드사 앱/홈페이지에서 이용내역을 복사해 붙여넣기 → 결제대행사로만 찍힌 결제는
   "결제처 확인" 탭에서 주문과 짝지어 줍니다.

## 맞춤 설정 (Code.gs 맨 위)

| 항목 | 의미 |
|---|---|
| `GMAIL_BACKFILL_DAYS` | 처음 동기화할 때 거슬러 올라갈 일수 (기본 365) |
| `GMAIL_QUERY` | 주문 메일을 찾는 Gmail 검색어 |
| `MALL_DOMAINS` | 메일 발신 도메인 → 쇼핑몰 이름 표 (자주 쓰는 몰 추가 가능) |
| `PG_NAMES` | 결제대행사로 볼 이름 목록 |
| `SEARCH_ALIASES` | 검색 시 같은 말로 볼 단어 (예: `['로지텍','logitech','logi']`) |
| `MATCH_DAY_WINDOW` | 결제대행사 결제와 주문을 짝지을 때 허용하는 날짜 차이 |

## 개인정보

- 웹앱 접근 권한이 "나만"이라 다른 사람은 열 수 없습니다.
- Gmail은 **읽기 전용** 권한만 씁니다. 메일을 지우거나 보내지 않습니다.
- AI 인식을 켜면 주문 메일 본문/캡처 이미지가 상품 정보 추출을 위해 Anthropic API로 전송됩니다.
  원치 않으면 API 키를 등록하지 않으면 됩니다(제목·금액 기반 기록만 동작).
